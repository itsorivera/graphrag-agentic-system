# Lecture: LLM Sampling Strategies & Randomness Control

## 1. The Stochastic Nature of Token Selection

Every token generated by a Large Language Model is the result of a **weighted random choice**. Understanding how to decode and control this probability distribution is critical for tuning an LLM's behavior in a RAG system.

![Probability Distribution](/rag-lectures/assets/probability-distribution.png)
_Source: [Retrieval-Augmented Generation by Zain Hasan - DeepLearning.AI](https://www.deeplearning.ai/courses/retrieval-augmented-generation/)_

- **Spiky Distribution**: Indicates high confidence, where one or few tokens dominate the probability.
- **Flat Distribution**: Indicates uncertainty, where many different tokens have a similar chance of being chosen.

## 2. Greedy Decoding: The Deterministic Baseline

![Greedy Decoding](/rag-lectures/assets/greedy-decoding.png)
_Source: [Retrieval-Augmented Generation by Zain Hasan - DeepLearning.AI](https://www.deeplearning.ai/courses/retrieval-augmented-generation/)_

**Greedy Decoding** is the simplest strategy: the model always selects the single token with the highest probability.

- **Pros**: It is **deterministic**; the same prompt will always yield the same response. This is ideal for code generation or debugging.
- **Cons**: It often results in "stilted" or generic text. More dangerously, it can cause the model to fall into **repetition loops**, where it repeats the same phrase indefinitely because the highest-probability path becomes circular.

## 3. Temperature: The Randomness Dial

**Temperature ($T$)** is a hyperparameter that scales the shape of the probability distribution without changing the order of the tokens.

![Temperature](/rag-lectures/assets/temperature.png)
_Source: [Retrieval-Augmented Generation by Zain Hasan - DeepLearning.AI](https://www.deeplearning.ai/courses/retrieval-augmented-generation/)_

- **$T = 1.0$**: The original distribution generated by the model.
- **$T < 1.0$ (Low)**: Makes the distribution "spikier." Standard for factual tasks and RAG grounding. Setting $T = 0$ is equivalent to greedy decoding.
- **$T > 1.0$ (High)**: Flattens the distribution, giving "unlikely" tokens a higher chance. This encourages variety and creativity but increases the risk of nonsense (hallucinations) if set too high.

## 4. Advanced Token Sampling Strategies: Top-K and Top-P

While temperature adjusts the weights, sampling filters define the **pool of tokens** that the model is allowed to choose from.

### Top-K Sampling

The model is restricted to choosing from the **top $K$** most likely tokens (e.g., $K=50$). This prevents the model from choosing extremely low-probability "nonsense" tokens from the tail of the distribution.

![Top-K Sampling](/rag-lectures/assets/top-k-sampling.png)
_Source: [Retrieval-Augmented Generation by Zain Hasan - DeepLearning.AI](https://www.deeplearning.ai/courses/retrieval-augmented-generation/)_

### Top-P (Nucleus) Sampling

Instead of a fixed number, **Top-P** limits the selection to a dynamic set of tokens whose **cumulative probability** meets a threshold (e.g., $P=0.85$).

![Top-P Sampling](/rag-lectures/assets/top-p-sampling.png)
_Source: [Retrieval-Augmented Generation by Zain Hasan - DeepLearning.AI](https://www.deeplearning.ai/courses/retrieval-augmented-generation/)_

- **Dynamic Advantage**: If the model is confident, the pool remains small. If the model is uncertain, the pool expands automatically to include more viable options.

![Top-P vs Top-K Sampling](/rag-lectures/assets/top-p-vs-top-k-sampling.png)
_Source: [Retrieval-Augmented Generation by Zain Hasan - DeepLearning.AI](https://www.deeplearning.ai/courses/retrieval-augmented-generation/)_

## 5. Advanced Logit & Frequency Controls

Beyond overall distribution shaping, developers can target specific linguistic patterns:

- **Repetition Penalty**: Decreases the probability of tokens that have already appeared in the completion, forcing the model to find more natural, varied phrasing.
- **Logit Biasing**: Manually boosting or suppressing specific tokens.
  - **Negative Bias**: Used to suppress profanity or unwanted words.
  - **Positive Bias**: Used in classifiers to ensure the model chooses from a set of predefined labels (e.g., "Positive", "Negative", "Neutral").

## 6. Strategic Configuration for RAG

Choosing the right parameters depends on the application's domain:

| Use Case             | Temperature ($T$) | Top-P ($P$) | Goal                               |
| :------------------- | :---------------- | :---------- | :--------------------------------- |
| **Fact-based / RAG** | 0.0 - 0.7         | 0.8 - 0.9   | High grounding, low hallucination  |
| **Code Completion**  | 0.0 (Greedy)      | N/A         | Predictability and syntax accuracy |
| **Creative Writing** | 1.0 - 1.3         | 0.9 - 1.0   | Variety, "interesting" tone        |

_Source: [Retrieval-Augmented Generation by Zain Hasan - DeepLearning.AI](https://www.deeplearning.ai/courses/retrieval-augmented-generation/)_

---

**Key Takeaway**: Controlling randomness is not about eliminating it, but about shaping it. By combining Temperature, Top-P, and Repetition Penalties, you can dial in an LLM’s behavior to be either a rigid factual assistant or a creative exploratory partner.
